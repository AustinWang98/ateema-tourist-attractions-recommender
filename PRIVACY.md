# Public Data and Privacy

This repository is the public demo edition of the recommender.

## Included data

- Public place names and stable catalog identifiers
- Public map coordinates and card metadata
- Deterministic events generated by `scripts/generate_demo_events.py`
- Synthetic user and session labels used only for local demonstrations

## Excluded data

- Raw analytics exports
- Real or pseudonymous visitor identifiers
- Account, client, advertising, and session identifiers
- Device fingerprints, precise visitor histories, and referrers
- Private cloud project names, resource inventories, and deployment records
- Credentials, service-account files, API keys, and local caches

Do not open a pull request containing production data. Store authorized local
exports only under `data/private/` and inspect staged changes before every push.

If public data may have been derived from a person or private system, stop and
confirm its provenance before committing it.
