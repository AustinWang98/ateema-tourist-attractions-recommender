# Contributing

Thank you for improving the recommender.

1. Create a focused branch from `main`.
2. Keep production credentials and private analytics data outside the repository.
3. Run `python -m pytest` and `node --check frontend/app.js`.
4. Explain the behavior change and tests in the pull request.
5. Use synthetic fixtures for tests and examples.

By contributing, you confirm that you have the right to submit the code and
data in your change. The repository does not currently grant an open-source
license.
